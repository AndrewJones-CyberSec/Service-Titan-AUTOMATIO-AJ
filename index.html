A small panel of time-savers for the ServiceTitan Dispatch board. Install it once and you always get the newest version.

What's inside

📝 Quick Notes

Click a job, then a note (or the other way round). It opens the customer, clicks Add Note and types the note for you. You check it and save.

🔕 Job Notifications

Pick a tech from the list, then check their jobs' notification switches or turn them all off, with live progress. Checking never changes anything.

💬 Tech Messages

Send your Good Morning or ETA message to the techs you pick. Only teams you approve can be messaged, and you can block anyone by name.

Install: drag it to your bookmarks bar

  1. Show your bookmarks bar if it's hidden. In Chrome, Edge or Firefox press Ctrl + Shift + B (on a Mac, Cmd + Shift + B). In Safari, choose View, then Show Favorites Bar.
  2. Click and hold the blue button, drag it onto the bookmarks bar, and let go.
  3. Open the ServiceTitan Dispatch board and click the new 🧰 Toolbox bookmark.
🧰 Toolbox Drag this, don't click it.

Had the older Quick Notes bookmark? You can delete it. Your edited notes carry over to the Toolbox.

If dragging doesn't work: copy and paste

  1. Click Copy bookmark code.
  2. Make a new bookmark named Toolbox:
    • Chrome or Edge: right-click the bookmarks bar and choose Add page (Edge: Add favorite).
    • Firefox: right-click the bookmarks toolbar and choose Add Bookmark.
    • Safari: bookmark any page into the Favorites bar, then right-click it and choose Edit Address.
  3. In the URL (or Address) box, delete what's there and paste. It should start with javascript:. Then save.

Pasting this into the address bar won't work, because browsers remove the javascript: part. It has to go in a bookmark.

Updates and warnings

The bookmark loads the newest Toolbox every time you click it, so there's nothing to reinstall. When a new version comes out, the Toolbox shows what changed the first time you open it.

If ServiceTitan changes something a tool relies on, a yellow bar at the top of the Toolbox says which tool is affected. Click Copy report and send it along so it can be fixed. You can also use 🩺 Check at the bottom of the menu any time.
